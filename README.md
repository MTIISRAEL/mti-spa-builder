# mti-spa-builder

מערכת ייצור, תכנון ומכירה לספא ובריכות זרמים (M.T.I).

אתר סטטי לגמרי — בדיוק כמו הקטלוג הדיגיטלי (מקלחונים): קובץ `index.html` אחד, React נטען מ-CDN בזמן טעינה, בלי Node, בלי בנייה, בלי שרת.

## איך צופים בו

פשוט פותחים את `index.html` בדפדפן (לחיצה כפולה), או מארחים אותו איפשהו (GitHub Pages וכו'). אין צורך להריץ שום פקודה.

## מבנה

- `index.html` — כל המערכת: לשוניות מכירתי / תכנון (שרטוט SVG) / ליקוט למחסן / ארכיון / תבניות יצרן.
- שמירת הזמנות ותבניות מתבצעת ב-`localStorage` של הדפדפן (`mes_spa_orders`, `mes_spa_presets`) — נשמר מקומית בכל מחשב/דפדפן בנפרד.
- תמונות דגמים: יש להוסיף קבצים בתיקיית `models/<מק"ט>.jpeg` (או jpg/png/webp) עבור כל דגם. בלי תמונה, הדגם פשוט לא יוצג בתצוגה (השדה יישאר ריק).

## הערה טכנית

הדף טוען את React, ReactDOM ו-lucide-react מ-CDN (esm.sh) ומתרגם את קוד ה-JSX/TypeScript בזמן טעינה בעזרת Babel (גם מ-CDN). המשמעות: נדרש חיבור אינטרנט כדי לטעון את הספריות בפעם הראשונה שפותחים את הדף בכל הפעלה של הדפדפן.
